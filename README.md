# Klar 5.0

Klar 是一个面向歌德 A1–B2 备考与德国日常生活的中英双注释德语学习网站。界面采用疏朗的液态玻璃与极简风格，每个页面控制在 1–5 个主要内容组，让词卡、例句、情景阅读、语法入口、四技能练习、视频和官方资料形成一条连续学习路径。

当前版本是完全静态的网站，不依赖数据库、API 密钥或 AI 服务，可直接部署到 GitHub Pages 等静态托管平台。

## 当前内容

- 10 个原创场景单元：A1 四个，A2、B1、B2 各两个；
- 120 张德中英词卡，每个单元 12 个词；
- 每张词卡 3 组德中英实际例句，共 360 组；
- 60 条德中英情景对话；
- 每个单元独立的语法规则、结构、例句、易错点、应用任务与参考表达；
- 听、说、读、写微练习和随机词义检查；
- 579 条固定德语课程 MP3，覆盖词语、例句、对话和语法示例；
- A1、A2、B1 官方词表与 B2 官方成人模考 PDF，可在网站内直接预览；
- 中文或英文注释一键切换；
- 自定义昵称、头像、头像主题和每日目标；
- 本地学习记录、间隔复习、句子收藏、拼写听写和学习进度。

Klar 的课程释义、讲解和三语例句为独立编写的精选内容，不是歌德学院的完整官方课程、完整词库或评分服务，也不保证考试通过。

## 使用方式

在项目目录运行：

```powershell
node server.cjs
```

然后访问 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。也可以执行 `npm start`。本地服务器只监听 `127.0.0.1`，并为 PDF 和 MP3 返回正确的媒体类型。

生产网站是纯静态文件；部署时不需要 `server.cjs`，只需发布本目录内容。

## 学习级别

A1–B2 级别只在“个人资料与设置”中切换。普通学习页、课程页、语法页和备考页不重复显示级别切换器，以减少页面噪声。保存新级别后，网站回到该级别的每日计划，并选择该级别第一个学习单元。

## 每日 00:00 重置

每日单词、例句安排、当日计数和临时学习队列使用设备本地日期。页面会计算距离下一次本地午夜的时间，并在 00:00 后重新生成当天安排。若电脑休眠或标签页在后台，页面重新获得焦点、恢复可见或系统时间变化时也会检查换日。

换日不会删除：

- 长期复习记录；
- 收藏的单词和句子；
- 单元进度；
- 写作与语法草稿；
- 个人资料与设置。

## 音频实现

正常与慢速不再使用 `SpeechSynthesisUtterance.rate`。某些操作系统语音会忽略或弱化该参数，这正是旧版“0.8× 听起来与正常速度一样”的根因。

Klar 5.0 为全部可点击课程文本预生成固定 MP3。正常与慢速播放使用同一个文件，并通过 `HTMLMediaElement` 设置：

```js
audio.defaultPlaybackRate = rate;
audio.playbackRate = rate; // 1 或 0.8
```

因此慢速播放的理论时长为正常播放的 `1 / 0.8 = 1.25` 倍，速度差异由浏览器媒体播放器保证，不依赖设备是否安装德语语音包。播放器还启用音高保持，并支持最多连续播放三次。

## AI 与录音

当前版本不提供 AI 学习搭档，也不采集麦克风录音。原因是无需配置即可直接使用的 AI 需要生产密钥管理、额度、服务端代理、内容安全与持续运行环境；纯静态 GitHub Pages 无法安全承载私密 API 密钥。为了避免提供一个无法开箱即用的半成品入口，本版移除了 AI 页面、服务端 AI 路由、录音按钮和麦克风权限代码。

口语练习保留固定示范音频、正常/0.8×/三次播放、独立复述任务与自查清单。

## 官方资料中心

“官方资料”页提供四个站内入口：

- A1：《Goethe-Zertifikat A1 Start Deutsch 1 Wortliste》，29 页；
- A2：《Goethe-Zertifikat A2 Wortliste》，32 页；
- B1：《Goethe-/ÖSD-Zertifikat B1 Wortliste》，104 页；
- B2：官方成人模考，51 页，包含听说读写四模块。

PDF 文件保存在 `materials/` 中，通过浏览器内置 PDF 阅读器嵌入页面。每份资料同时保留“单独打开 PDF”和“官网来源”链接。PDF 版权归歌德学院所有，Klar 仅提供集中预览入口。

官方来源：

- [歌德 A1 练习与词表](https://www.goethe.de/de/m/spr/prf/ueb/pa1.html)
- [歌德 A2 信息与词表](https://www.goethe.de/ins/de/de/m/prf/prf/gzsd2/wi2.html)
- [歌德 B1 练习与词表](https://www.goethe.de/de/m/spr/prf/ueb/pb1.html)
- [歌德 B2 练习与模考](https://www.goethe.de/de/m/spr/prf/ueb/pb2.html)

歌德当前为 B2 提供免费四模块模考材料，而不是与 A1–B1 相同形式的独立词表。因此 Klar 的 B2 内容按官方模考主题、题型和交际功能校准，界面明确标为“官方成人模考”。

## 数据与隐私

昵称、压缩后的头像、学习计划、复习记录、句子标签、单元位置和草稿保存在当前浏览器的 `localStorage`。头像只在浏览器中处理，不上传。网站没有账号系统、AI 请求、麦克风采集或学习数据上传。

清除站点数据、更换浏览器或更换部署域名会影响可见记录。学习记录页提供 JSON 导出入口。

## 外部媒体

配套视频使用 Easy German / Easy Languages 的 YouTube 隐私增强嵌入和来源链接，仅作主题拓展，不是歌德官方分级视频。视频和缩略图需要联网；固定课程 MP3 与官方 PDF 不依赖第三方页面。

## 文件结构

| 文件或目录 | 作用 |
|---|---|
| `index.html` | 静态入口与 v5 资源加载顺序 |
| `data.js` | A1–B2 基础课程数据 |
| `vocabulary.js` | 扩充词汇、第三条例句和官方资料映射 |
| `lessons.js` | 单元对话、阅读检查与单元语法 |
| `official-a1.js` | 基于用户提供 A1 PDF 校准的新增 A1 内容 |
| `app.js` | 外壳、词卡、设置、资料中心与基础交互 |
| `pathway.js` | 每日路径、阅读、词典、句子本、拼写和跟读 |
| `assessment.js` | 单元化听说读写与词义练习 |
| `audio-manifest.js` | 课程文本到固定 MP3 的映射 |
| `audio.js` | `HTMLMediaElement` 精确速率播放器 |
| `audio/` | 579 条固定德语 MP3 |
| `materials/` | A1–B2 官方参考 PDF |
| `daily.js` | 本地午夜换日逻辑 |
| `player.js` | 视频悬浮、保活与返回课程 |
| `styles.css`、`pathway.css`、`glass.css` | 响应式布局、学习组件和液态玻璃视觉 |
| `server.cjs` | 仅用于本地预览的静态服务器 |
| `tests/pathway.cjs` | 浏览器集成、媒体速率、资料预览和响应式测试 |

## 验证

```powershell
npm run check
npm test
```

集成测试覆盖：

- 120 张词卡、360 组例句和 579 条音频映射；
- A1–B2 设置内切换与持久化；
- 本地午夜换日及长期记录保留；
- 四份 PDF 的 HTTP 类型、文件大小和站内预览切换；
- 正常 `1×` 与慢速 `0.8×` 使用相同媒体机制；
- 慢速理论时长是正常时长的 1.25 倍；
- 阅读、词典、语法、四技能练习和资料入口连接；
- 320、390、768、1024、1440 像素宽度下无横向溢出；
- 所有主要页面保持 1–5 个主要内容组；
- 无未捕获的浏览器 JavaScript 错误。

## GitHub Pages

项目内置 `.github/workflows/pages.yml`。先在公开仓库 **Settings → Pages** 中把 Source 设为 **GitHub Actions**，再把本目录内容推送到 `main` 分支；工作流会上传完整静态站点并部署。若使用个人主页仓库，网址格式为 `https://用户名.github.io/`；普通项目仓库通常为 `https://用户名.github.io/仓库名/`。GitHub 官方要求自定义 Pages 工作流先在仓库中启用，并至少授予 `pages: write` 与 `id-token: write`，本工作流已包含这些权限。
